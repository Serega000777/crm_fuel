# Data Model

- `users`: Telegram ID, имя, роль.
- `fuels`: справочник, остаток, цены, средняя себестоимость, порог и цвет.
- `operations`: неизменяемый факт закупки, продажи, расхода, инкассации или
  reversal; описание, прямые расходы закупки, idempotency key и ссылка на
  отменяемую операцию.
- `ledger_entries`: денежные проводки по операции.

Первичные бизнес-идентификаторы — UUID. Деньги — `BIGINT` в копейках, литры —
`NUMERIC(18,3)`. Удаление проведённых операций запрещено на уровне приложения.
