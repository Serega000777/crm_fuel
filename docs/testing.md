# Тестирование

Unit-тесты проверяют округление денежных значений. Интеграционные тесты проводят
закупку, продажу, расход, инкассацию и reversal, сверяют остаток, кассу, выручку,
прибыль и неизменяемую историю.

Security-набор проверяет Telegram HMAC/freshness, production fail-closed config,
RBAC, привязку idempotency key к payload, запрет перерасхода кассы, rate limiting
и HTTP security headers. Сумма ledger-проводок каждой операции обязана быть нулевой.

Тесты анализа закупки проверяют доставку и прочие расходы, полную и
средневзвешенную себестоимость и предупреждение об отрицательной марже.

Тест отчётов сверяет выручку, COGS, расходы, прибыль, денежный поток, объёмы
топлива и UTF-8 CSV-выгрузку за выбранный период.

История операций тестируется с limit/offset и фильтрацией по типу.

Инвентаризация проверяется на изменение фактического остатка, баланс ledger,
owner-only RBAC и восстановление исходного остатка через reversal.

CI запускает PostgreSQL 16, применяет все миграции Alembic и выполняет
`tests/postgres_concurrency.py` с отдельными соединениями: overselling,
параллельная идемпотентность и баланс ledger.

Команды: `pytest`, `ruff check .`, `mypy app`, `pip-audit`,
`npm run lint`, `npm run build`, `npm audit`.
