# Тестирование

Unit-тест проверяет единое округление денежных значений. Интеграционные тесты
проводят закупку, продажу, расход, инкассацию и reversal, сверяют остаток, кассу,
выручку и прибыль, а также подтверждают сохранение исходной истории.

Security-набор проверяет Telegram HMAC/freshness, production fail-closed config,
RBAC, привязку idempotency key к payload, запрет перерасхода кассы, rate limiting
и HTTP security headers. Отдельный инвариант требует нулевую сумму ledger-проводок
каждой операции.

Тесты анализа закупки проверяют включение доставки и прочих расходов в стоимость
партии, средневзвешенную себестоимость и предупреждение об отрицательной марже.

CI запускает PostgreSQL 16, применяет все миграции Alembic и выполняет
`tests/postgres_concurrency.py`. Сценарий использует отдельные соединения и
проверяет защиту от overselling, параллельную идемпотентность и баланс ledger.

Команды: `pytest`, `ruff check .`, `mypy app`, `pip-audit`,
`npm run lint`, `npm run build`, `npm audit`.
