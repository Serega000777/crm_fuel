# Testing

Unit test проверяет единое округление. Интеграционный тест проводит закупку,
повторяет её с тем же ключом, задаёт цену, продаёт топливо и сверяет остаток,
выручку и прибыль. Отдельный тест запрещает продажу сверх остатка.

Команды: `pytest`, `ruff check .`, `mypy app`, `npm run lint`, `npm run build`.
