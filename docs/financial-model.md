# Financial Model

`выручка = Σ(литры продажи × цена продажи)`.

При закупке средняя себестоимость:
`(старый остаток × старая средняя + закупленные литры × закупочная цена) /
новый остаток`.

`себестоимость продажи = проданные литры × средняя себестоимость на момент продажи`.
`валовая прибыль = выручка − себестоимость продаж`.
`чистая прибыль = валовая прибыль − расходы`.

Деньги округляются до копейки правилом ROUND_HALF_UP. Закупка, остаток,
операция и проводки фиксируются одной транзакцией. Повтор с тем же
idempotency key возвращает исходную операцию. Исправление проведённой операции
будет отрицательной reversal-операцией, а не удалением истории.

Касса — сумма проводок счёта `cash`. Частичная или полная инкассация создаёт
перевод из `cash` в `collection`, не обнуляя и не удаляя прошлые проводки.
Она не может превышать доступный положительный баланс.

Reversal ссылается на исходную операцию, создаёт противоположные ledger-проводки
и корректирует склад для закупки/продажи. Одна операция может быть отменена
только один раз; сама reversal-операция повторно не отменяется.

Ledger использует знаки двойной записи: увеличение активов положительно,
увеличение доходов отрицательно. Сумма проводок каждой операции равна нулю.
Idempotency key связан с SHA-256 отпечатком типа операции и нормализованного
payload; повтор с другим содержимым отклоняется.
