# Financial Model

`выручка = Σ(литры продажи × цена продажи)`.

При закупке средняя себестоимость:
`(старый остаток × старая средняя + закупленные литры × закупочная цена) /
новый остаток`.

`себестоимость продажи = проданные литры × средняя себестоимость на момент продажи`.
`валовая прибыль = выручка − себестоимость продаж`.
`чистая прибыль = валовая прибыль − расходы` (расходы — следующий этап).

Деньги округляются до копейки правилом ROUND_HALF_UP. Закупка, остаток,
операция и проводки фиксируются одной транзакцией. Повтор с тем же
idempotency key возвращает исходную операцию. Исправление проведённой операции
будет отрицательной reversal-операцией, а не удалением истории.

Касса — сумма проводок счёта `cash`. Инкассация в следующих итерациях создаст
перевод из `cash` в `collection`, не обнуляя и не удаляя прошлые проводки.
