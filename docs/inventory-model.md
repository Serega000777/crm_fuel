# Inventory Model

Закупка увеличивает остаток, продажа уменьшает. Отрицательный остаток запрещён.
Каждая операция хранит литры и моментальную цену. Корректировки будут отдельными
движениями с причиной и аудитом. Начальные позиции — АИ-92, АИ-95, АИ-100 и ДТ;
домен не ограничен этими четырьмя позициями.

Фактическое расхождение резервуара оформляется операцией `adjustment`, а не
прямым изменением строки топлива. Операция хранит разницу литров, стоимость
расхождения по текущей средней себестоимости и балансирующие счета `inventory` /
`inventory_adjustment`. Ошибочный замер исправляется только reversal.
